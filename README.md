An interactive command-line quiz game that tests your programming knowledge — built with pure Node.js and zero external dependencies.

## About

This is a small command-line quiz app written in Node.js. It reads questions from data/questions.json and runs an interactive quiz in the terminal.

## Installation

1. Clone the repository:

   git clone https://github.com/leokotman/test-app.git
2. Install dependencies:

   npm install

## Usage

Run the quiz with:

   node index.js

## Development

- Source files are in src/
- Questions are stored in data/questions.json
